# Minh chứng Git

Lưu ảnh thật theo người: `MaSV_HoTen/`.

Ảnh cần thể hiện push thành công lên nhánh cá nhân, commit liên quan và PR đã merge vào `dev`. Khi nộp Classroom, dùng `MaSV_HoTen.png` theo đề; có thể ghép các ảnh thật thành một PNG rõ ràng.

Không có ảnh minh chứng tự sinh trong repo mẫu. Sau khi push/merge thật, mới chụp và bổ sung.
