# Katalon Recorder suites

Thư mục dành cho các suite được record, chỉnh assertion, chạy kiểm tra và export từ Katalon Recorder.

Hiện chưa có suite thực thi. Không xem các tài liệu test design là automation scripts đã chạy.

Khi bổ sung, dùng thư mục theo chức năng và kèm README: phiên bản extension/browser, file suite cần import, dữ liệu cần tải vào, tiền điều kiện, cách reset và cách chạy. Tránh lưu tài khoản thật hoặc phiên đăng nhập vào Git.
